# CORE// 计算机解剖实验室

一个**单文件**交互式网站：拆开一台计算机，看清 7 大部件的结构，以及它们如何协作把机器跑起来。

> 纯 HTML / CSS / JS · 零依赖 · 无构建步骤 · 单文件即整站

## ✨ 特性

- **部件图鉴** — CPU / 主板 / 内存 / 显卡 / SSD / 电源 / 散热，7 个部件各有详情弹层：AI 渲染图、核心参数、在启动链路中的位置
- **拆解工作台** — CPU 封装五层逐层下探（顶盖 → 导热硅脂 → 晶粒 → 基板 → 触点），主图高亮带、信息块、聚焦面板全联动，支持 ←/→ 键盘切换
- **协作流程** — 按下电源键之后的启动链路动画（STEP 01-06），支持播放/暂停、2× 倍速、分段 seek
- **数据旅程** — 从输入到屏幕上的一帧像素
- **深浅双主题** — 一键切换，localStorage 持久化
- **响应式** — 1440 基线设计，390 ~ 1440 全宽度零溢出

## 🚀 运行

无需安装任何东西，直接用浏览器打开 `index.html` 即可；或起一个本地服务：

```bash
python -m http.server 8765 --directory core-lab
# 访问 http://127.0.0.1:8765
```
